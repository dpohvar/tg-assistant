For a new run, use the designated test bot only, with its regular service stopped, a private JSON config containing controllerActive=false, username, botTelegramId, ownerId, token or tokenFile, and an absolute codexExecutable. The config must stay outside the worktree. Provide a fresh state directory and a group chat ID:

    node test/manual/react-wordle-acceptance.mjs --config PRIVATE_JSON --state-dir NEW_DIR --chat-id GROUP_ID

The bounded runner verifies the bot/group, copies the `examples/widgets/wordle` source into isolated bot files, publishes Players and GameInput as two messages, then polls callbacks for up to 20 minutes. It prints a probe ID and two commands. Two users can open their separate private boards. The owner may send `/wordle_finish PROBE_ID` in that group to reveal the answer and close overlays, then `/wordle_stop PROBE_ID` to end the runner. In probe `dff2ac`, the finish command was not observed by the runner, so the operator created `STATE_DIR/stop`; the runner finished the round in its shutdown path. The cause of the missing command update remains unconfirmed. On timeout or stop it finishes the round before closing. It leaves the final public messages for inspection and writes events.jsonl in the state directory. The runner does not invoke a model, does not start another bot service, and never prints the token.
