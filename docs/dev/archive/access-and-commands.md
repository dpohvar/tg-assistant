# Роли и команды

Актуальный полный набор команд: [commands.md](commands.md).

Права наследуются user → manager → admin → owner и назначаются отдельно
для каждого бота. Telegram-администратор не получает роль приложения автоматически.
User работает в собственном ЛС, manager дополнительно управляет текущей группой,
admin управляет ботом, но не назначает администраторов и владельца.
Owner назначает администраторов и передаёт владение.
Мастер доступен только serviceOwnerId из конфигурации.

Новые группы и нефорумные супергруппы подключаются пассивно; /agent start
включает агента. /agent stop сохраняет заметки, историю, модель и задачи.
/agent clear сбрасывает контекст с сохранением очереди. /chat leave выходит
и удаляет связанные данные диалога. Форумные группы запрещены.

Смена команд не меняет границы инструментов: история чужих личных чатов закрыта,
данные разных ботов изолированы. Неавторизованные ЛС игнорируются.

Ответы команд — reply. Ошибки синтаксиса предлагают /help раздела.
Вне code/pre пробельные символы разделяют аргументы; code/pre сохраняют
содержимое как один аргумент. Прочее форматирование запрещено.
Старые имена заменённых команд удалены без алиасов.

Для /rules set и /upload проверяется собственное неотредактированное
цитируемое сообщение в текущем чате в обоих направлениях reply.
Недопустимый файл не передаётся агенту. Git-токены не сохраняются в истории
и удаляются из сообщений команд независимо от успешности операции.
